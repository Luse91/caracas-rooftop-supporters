Conectar este navegador

Solo se hace una vez (si ya lo conectaste para los Panas, sirve el mismo). La página necesita un permiso de GitHub para poder guardar las pancartas.

  1. Abre este enlace de GitHub (ya viene rellenado).
  2. En Repository access elige Only select repositories y marca caracas-rooftop-supporters.
  3. Baja hasta el final, pulsa Generate token y copia el código que empieza por github_pat_.
  4. Pégalo aquí:

El permiso se guarda solo en este navegador.

Las 6 pancartas

Toca una pancarta para cambiarla. Las del frente se ven desde la acera; las del lado desde la esquina. En el mundo cambian solas, unos minutos después de guardar: en las instancias nuevas al entrar y en las ya abiertas en menos de 30 minutos.
